## About the original project (historical)

`graphx` was an experimental library for visualizing and analysing GraphQL query results as a true graph, built on top of [d3](https://d3js.org/) and [graphql-s2s](https://github.com/nicolasdao/graphql-s2s). It was never taken past an alpha stage and has not been maintained since June 2017.

The source is kept in `src/`, the webpack build in `lib/`, and the release history in [CHANGELOG.md](./CHANGELOG.md).
